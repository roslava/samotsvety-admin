# Классификация и Samotsvety Markdown v1

Форма «Научные свойства» содержит три независимых необязательных списка: `mineral_group`, `chemical_class`, `catalog_family`. Коды и подписи RU/EN хранятся в `lib/classification.ts`; варианты формы берутся из него же. API принимает те же коды. Добавление кода требует обновить каталог Admin и валидатор API.

В Markdown v1 строки `mineral_group`, `chemical_class`, `catalog_family` находятся в существующей таблице «Научные данные». Их можно оставить пустыми или совсем пропустить. Маркер версии и остальные разделы не меняются; старые v1 файлы продолжают импортироваться. Экспорт записывает эти строки и повторно проверяет результат импортом. Значения указываются кодами, например:

```markdown
| mineral_group | olivine_group |
| chemical_class | silicates |
| catalog_family |  |
```

`mineral_class` и `mineral_family` — старые поля. Форма показывает их сохранённые коды в примечании, но не переносит их в новые поля автоматически. При редактировании следует сверить источник и выбрать новое значение явно. `type` не меняется.

Примеры и спорные случаи описаны в `samotsvety-api/docs/CLASSIFICATION.md`. Опал не получает минеральную группу, обсидиан не получает минеральную группу или химический класс, а камбаба-яшма может иметь `catalog_family=jaspers` без кварцевой принадлежности.
