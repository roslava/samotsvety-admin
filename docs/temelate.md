## Назначение

Этот Markdown-документ служит **чек-листом и руководством** для сбора и структурирования всей необходимой информации перед созданием JSON-записи **самоцвета, минерала или горной породы** в базе данных. 

Он помогает:
- Систематизировать сбор данных из надежных источников (Mindat, Wikipedia, научная литература, специализированные книги по самоцветам).
- Избежать пропусков полей.

## 1. Основная информация

**Type** (тип сущности) — **обязательно**:
- `mineral` — минерал
- `rock` — горная порода / агрегат
- `gem_variety` — разновидность (например, демантоид как разновидность граната)
- `organic` — органический материал (янтарь, жемчуг)

**Slug** (уникальный идентификатор в URL):
- Формат: `lowercase-with-hyphens` (например, `malachite`, `charoite`, `demantoid-garnet`)
- Должен быть уникальным, латинским, без специальных символов.
- Рекомендация: использовать английское название или транслит.

**Приоритет камня** (для roadmap): Российский / Важный / Стандартный

## 2. Научные данные (`scientific`)

**Важно:** Не все самоцветы — минералы. Некоторые являются **горными породами** (например, яшма, нефрит). Для пород некоторые поля (chemical_formula, crystal_system) могут быть не применимы или заполняться обобщённо.

Заполняйте **только проверенными фактами**. Источники: Mindat.org, Webmineral, научные публикации, геологические справочники.

| Поле (JSON path)              | Тип данных          | Инструкции по заполнению                                                                 | Пример / Примечания                          | Обязательно |
|-------------------------------|---------------------|------------------------------------------------------------------------------------------|----------------------------------------------|-------------|
| `scientific.chemical_formula` | string             | Точная химическая формула (для пород — опционально)                                     | `Cu₂CO₃(OH)₂` или `—`                        | Условно     |
| `scientific.mineral_group`    | string             | Группа минерала / тип породы (на русском)                                                | `карбонаты` или `метаморфические породы`    | Да          |
| `scientific.crystal_system`   | string             | Кристаллическая система (для пород — опционально)                                        | `моноклинная` или `—`                        | Условно     |
| `scientific.crystal_habit`    | string             | Формы кристаллов и агрегатов (перечислить через запятую)                                | `призматический, волокнистый, почковидный`  | Нет         |
| `scientific.hardness.min`     | number             | Минимальная твёрдость по Моосу                                                           | `3.5`                                        | Да          |
| `scientific.hardness.max`     | number             | Максимальная твёрдость по Моосу                                                          | `4.0`                                        | Да          |
| `scientific.hardness.note`    | string (опц.)      | Дополнительная заметка                                                                   | `по шкале Мооса`                             | Нет         |
| `scientific.specific_gravity.min` | number         | Минимальный удельный вес                                                                 | `3.6`                                        | Да          |
| `scientific.specific_gravity.max` | number         | Максимальный удельный вес                                                                | `4.05`                                       | Да          |
| `scientific.streak`           | string             | Цвет черты                                                                               | `зелёная`                                    | Да          |
| `scientific.luster`           | string             | Блеск (перечислить варианты)                                                             | `стеклянный, шелковистый, матовый`          | Да          |
| `scientific.transparency`     | string             | Прозрачность                                                                             | `непрозрачный, полупрозрачный`              | Да          |
| `scientific.cleavage`         | string             | Спайность                                                                                | `совершенная по {100}`                       | Нет         |
| `scientific.fracture`         | string             | Излом                                                                                    | `неровный, раковистый`                       | Нет         |
| `scientific.tenacity`         | string             | Крепость/хрупкость                                                                       | `хрупкий`                                    | Нет         |
| `scientific.rarity`           | enum               | `common`, `uncommon`, `rare`, `very_rare`                                                | `common`                                     | Да          |
| `scientific.ima_status`       | string             | Статус одобрения IMA                                                                     | `approved`                                   | Нет         |
| `scientific.identification_tips` | string          | Советы по отличию от похожих минералов                                                  | `Отличается от ... по ...`                   | Нет         |
| `scientific.composition`      | string             | Преобладающий состав (особенно полезно для пород)                                        | `кварц + халцедон + примеси`                 | Нет         |
| `scientific.rock_type`        | string             | Тип горной породы (metamorphic, igneous, sedimentary)                                    | `metamorphic`                                | Нет (для пород) |
| `scientific.phenomena`        | array of strings   | Оптические эффекты (астеризм, иризация, кошачий глаз и т.д.)                            | `["chatoyancy", "asterism"]`                 | Нет         |
